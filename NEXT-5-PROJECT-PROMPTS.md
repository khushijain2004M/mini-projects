# Projects 31–35 — Detailed Build Prompts

These five websites are original portfolio builds. The linked open-source repositories are product references only; do not copy their code, branding, content corpus, or layout.

## 31. CodeForge Academy

Build a responsive self-paced coding-learning dashboard called **CodeForge Academy**. Use a near-black background with deep blue, violet and hot-pink light, subtle grid lines, glass panels and restrained motion. Include a learning-path sidebar, HTML/CSS/JavaScript modules, lesson progress, XP/streak metrics, an editable code challenge, live preview, runnable tests, hints, lesson completion and local persistence. The first screen must feel useful without login. Add keyboard-friendly controls, clear empty/error/success states and a Khushi Jain footer with GitHub, LinkedIn, email and portfolio links.

## 32. Frontend Quality Inspector

Build a practical front-end audit website named **Frontend Quality Inspector**. Use deep navy and black panels with cyan, red and purple priority accents. Provide grouped checklist rules for HTML, accessibility, performance, SEO, security and responsive design; search, category and priority filters; pass/fail toggles; completion score; issue counts; reset; and downloadable report. Persist the audit locally. Every rule needs a short remediation hint. Make the dashboard easy to scan on mobile and desktop, with animated progress rings/bars and Khushi branding.

## 33. Interview Mastery Hub

Build an interview-practice website named **Interview Mastery Hub** with a dark purple/blue/pink command-center aesthetic. Include a curated question bank for HTML, CSS, JavaScript, React and behavioural interviews, difficulty filters, search, random-question mode, answer reveal, confidence rating, bookmarks, personal notes, mock-interview timer and session statistics. Save user state in localStorage. Keep content concise and original. Include accessible controls, responsive panels, gentle transitions and Khushi Jain contact footer.

## 34. NovaUI Framework

Build **NovaUI Framework**, a browser-based component playground rather than a real production package. Use a black canvas with deep indigo, magenta and red glow. Show a component catalogue for buttons, inputs, cards, alerts and badges, a live preview, editable accent colour, corner radius and density controls, state variants, responsive preview sizes, generated HTML/CSS code and one-click copy. All previews must update immediately. Provide usage guidance, design tokens, accessible focus states and a polished Khushi-branded footer.

## 35. Developer Journey Roadmap

Build an interactive career roadmap named **Developer Journey Roadmap**. Use a deep-space black/blue theme with pink, violet and red route lines. Let users select Frontend, Backend or Full Stack tracks, then display staged skill nodes with descriptions, estimated effort, resources, prerequisites and status controls (not started, learning, completed). Include overall/stage progress, search, next recommended skill, notes, reset and export. Persist progress locally. Use a visual node path that collapses cleanly on mobile and finish with Khushi Jain identity/contact links.

## Shared acceptance standard

- Standalone HTML, CSS and JavaScript; no build step and no required API key.
- Fully usable at 320px width and with keyboard navigation.
- Functional interactions, local persistence and visible feedback—not decorative mock buttons.
- Original copy and UI; references are used only to understand the product category.
- Deep black plus dark red, blue, pink and purple palette; motion respects reduced-motion preference.
- Footer credit: “Built by Khushi Jain” with GitHub, LinkedIn, email and portfolio.
